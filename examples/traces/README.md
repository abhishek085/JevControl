# Example call logs for the Import page

`support_desk_llm_only.jsonl` is a **synthetic** log: what an LLM-only version of the bundled support-desk
agent would write to its logs. Five prompted steps per ticket (guardrail, routing, sufficiency, one relevance
call per article, then the reply), each with the prompt, the reply, token counts and a latency.

It is generated by `scripts/make_example_trace.py` from the demo task set's ground truth with deliberate noise
and drawn timings — **no model is called to produce it**, so its numbers measure nothing. It exists so the
Import page can be tried in a few seconds without instrumenting anything.

The other four files are a different, **also synthetic**, shape: a run-tree export (one parent run, several
child runs, tool calls included) instead of a flat one-row-per-call log. The Import page recognises the shape
on its own — or you can pick the category explicitly above the paste box — and shows it as the **agent
flow**, judged as a Jev candidate or not by a real local model you pick, never by any tag the export carries.

- `agent_run_tree_sample.json` / `support_agent_langfuse_sample.json` / `support_agent_otlp_sample.json` are
  the *same* synthetic support-desk scenario in each of the three shapes JevControl reads (LangSmith,
  Langfuse v2 observations, and OpenTelemetry/OTLP) — parse any of the three and you get identical numbers.
- `shopping_agent_run_tree.json` additionally exercises the wider LangSmith shape some real dumps use: a bare
  array (no `runs` wrapper), `extra.metadata` instead of top-level `metadata`, and flat
  `prompt_tokens`/`completion_tokens`/`total_cost` fields instead of a `usage` object.

See [docs/TRACES.md](../../docs/TRACES.md#an-agent-execution-export-a-run-tree-langsmith-langfuse-or-opentelemetry).

For a real log of your own, either export whatever your app already records (any JSONL with a prompt and a
reply per line works — see [docs/TRACES.md](../../docs/TRACES.md)), or capture one from a JevControl baseline
run: set `capture: true` in the experiment config, then

```bash
jevcontrol export-trace .jevcontrol/experiments/<run-id> -o my_trace.jsonl
```
